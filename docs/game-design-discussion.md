详细的前五轮讨论完整保存在 [0.5 历史稿](history/game-design-discussion-v0.5.md)，包括画风探索、演出草案、平台与模式的取舍。本页记录最新有效决定；历史提案不自动成为任务。

## 当前产品方向

Windows 与 macOS 本地安装，电脑优先；首次创建本机玩家档案，不做联网注册登录、硬件绑定、等级、解锁、经验评分、排位、公开匹配或移动端。

离线先做自己对一个 AI，资源与所用 AI 在本机运行；联机 2—6 位真人，房间号加入，房主可选设置密码，观众容量与六个参战位分别计算。暂不自由添加多人 AI。单人／联机与经典／扩展玩法分别组织；首版只有经典，贷款、火力大乱斗、血量以后逐项加入。

保留高中原味、同时选择和共同揭晓。默认对全场出招，暂不选目标。下方自己的卡牌与资源，卡牌上方明显倒计时，中间战况，周围玩家。采用第二张生成概念图的柔和手绘气质，不做像素和手势。图片中的人物、猫咪和示例功能未获最终确认。

具体页面由 ChatGPT 先安排信息，再由 Codex 出布局图供 Teddy 选择。最终页面制作后置。逐招详细确认、分类与数据表示先于完整动画系统设计；历史动画草案仅供未来参考。

## 本次接受的前轮建议

Teddy 表示前轮建议同意并保留，以下从候选转为当前安排：

- 单人首版自己对一个 AI；不再保留首版 1—10 个 AI 的承诺。
- 连续三轮未本人有效出牌才退出；本人有效提交清零；系统默认攒与 AI 代选不清零；准备和观战者不计。
- 双人超时可 AI 代选，多人超时默认攒；按开局类型保持，多人淘汰到两人时不突然引入 AI。
- 六个参战席位与观众容量分开；淘汰可留房等下一局或退出。
- 房主淘汰但留房，房间继续；房主主动离开先提醒，然后结束房间，其他人返回联机入口。
- 安装包让朋友直接启动，不要求他们安装 Python 或开发环境；Windows 与 macOS 各做实机，并测试互联。
- 联机安排独立房间通信服务，单机不依赖它；不做云端账号。服务商、部署与费用未选。

仍待决定：观众数量、房主意外断网的恢复时间、第三次缺席的移除时刻、出牌时长与提交后改选、房间号格式、最低系统版本和最终 IP。接受保留一个待讨论项不代表已经批准其具体数值。

## 新的协作方式

Teddy 明确要求：ChatGPT 写详细 PRD、负责架构与页面信息，再发编号工作包；Codex 按包执行、实机测试、把证据和代码交回 GitHub；Teddy 回来后由 ChatGPT 查结果与实际代码验收。Codex 不代替 ChatGPT 编写 PRD 或架构。

命名例：第一轮｜任务 01｜a｜游戏规则详细确认；R01 为大轮次，T01 为主题任务，a/b/c 为这个主题的执行包次。等待问题答案或其他结果后由 ChatGPT 发下一字母，Codex 不自行推进。
