# PRD-R02-LIVE 1.0｜本地真实单人循环

ChatGPT · 2026-09-13。服务R02-T04-a；在原R02的离线目标内推进，不改变classic-1.0.1。

## 这一包交付什么

从当前桌面原型进入单人后，玩家面对一个明确标注的临时随机对手；牌的资格、费用、胜负、收益、曾义休整和再次开场，都由已经验收的真实核心产生。可从源码启动，不需要开发网页服务；此包不交正式安装版。

| ID | 要求 | 验收依据 |
| --- | --- | --- |
| L01 | 单人入口连接本地worker与真实核心，所有33牌的可用性来自list_options | source=live；脚本演示不混用 |
| L02 | 选择、提交、揭晓、下一拍、整场结束、再来一场形成完整循环 | 多轮操作录像/截图与准确日志 |
| L03 | 曾义休整自动执行，无需点击灰牌；重复请求不重复扣款/发奖 | Session单测及C081关联测试 |
| L04 | 临时随机对手在玩家选招前选好，无法读取玩家当轮选择 | 出招函数的输入检查和固定seed测试 |
| L05 | 对手公开资源可读，DD通用精确显示；保持33牌和现有画风 | 两种目标内容区截图与断言 |
| L06 | 超时、worker退出、读取失败和晚到响应有明确处理 | 不静默卡在等待、不偷偷开新局 |
| L07 | 真实结果保留回合账目；新局重开不复活淘汰者 | 192份原独立样本继续通过；会话新测分开 |
| L08 | 单机数据不依赖网络；档案与设置不受对局进程重启影响 | 本地资源/无远程URL检查，物理断网仍需真人证据 |

没有复杂AI策略、专家模型宣称、多人AI、联机房间、排行或成长。纯核心仍支持2—6人供测试，单人产品只开放1v1。
