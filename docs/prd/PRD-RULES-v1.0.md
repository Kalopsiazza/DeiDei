# PRD-RULES 1.0｜经典规则与判定目标

作者：ChatGPT　日期：2026-09-12  
状态：规划规格已编写；尚未发出对应的正式编码工作包。

## 目标

让 Windows／macOS 新游戏、离线临时 AI 对战、2—6 人好友局、玩家说明与后续演出读取同一套经典规则结果。玩家不需要了解程序字段，也能知道费用、可用条件、主要效果与关键例外；开发者能为每条判定找到具体来源和预期案例。

规则正文只在 [RULEBOOK.md](../rules/v1/RULEBOOK.md) 维护；本 PRD 不复制第二份招式数值表。玩家短文见 [PLAYER-GUIDE.md](../rules/v1/PLAYER-GUIDE.md)，程序设计见 [RULE-ENGINE-v1.0.md](../architecture/RULE-ENGINE-v1.0.md)。

## 本版不做

不实现血量、贷款、火力大乱斗、组队、多人 AI、联网账户、等级、卡牌解锁、公开匹配、排位。不绘制最终 IP，不设计具体招式动画时间线，不决定房间服务器供应商。不把所有动作做成可由任意用户脚本扩展的通用引擎。

## 验收层次

本次完成的是任务 01 的证据验收和 ChatGPT 的规范重写。以后正式规则实现通过的条件为：规范案例实际执行、属性不变量通过、源码审阅完成、无未说明的当前可达规则缺项；然后再检查离线和联机运行。

文档静态检查只检验编号、链接、入口覆盖、来源对应、标记和格式。不能把其结果写成新游戏已经通过测试。桌面技术候选与 Windows 未测等问题仍由任务 02 独立报告；UI 概念图也不能当作规则或运行证据。
