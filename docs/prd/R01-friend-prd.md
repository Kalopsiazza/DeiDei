# FRIEND-R01｜协作任务 PRD 1.0

## F04｜Windows 实机复测

目标：拿一个固定版本的已有运行包，在普通 Windows 笔记本检查真实启动、本机存储、简单 AI、退出和断网表现。先测运行包再考虑安装开发依赖，避免破坏“无需 Python/Node”的验证条件。它是旧规则技术实验，新规则的80组案例不属于本包。

| 验收编号 | 检查内容 | 成功证据 |
| --- | --- | --- |
| W01 | 取包与来源 | 指定 run/artifact、内部ZIP hash/字节数、代码SHA相符 |
| W02 | 普通双击与中文空格路径 | 真实窗口标题、6席位、3张素材、Health ready；系统/分辨率/缩放已记录 |
| W03 | 档案与错误提示 | 测试昵称、localId 重开仍保留；空昵称/非法seed报错且原档案保持 |
| W04 | 固定案例与简单AI | 四个案例预期结果、seed42重复相同、标明 Easy heuristic |
| W05 | 进程与协议 | 10次启停；对应worker路径/PID退出；停止后恢复；代码回归另列结果 |
| W06 | 真正断网 | 同学先关闭程序，断开Wi-Fi/网线，再双击测W02—W04，最后恢复；与联网结果分别记录 |
| W07 | 无开发运行时 | 无Python/Node的测试机或干净虚拟机运行；若机器已安装则 NOT_RUN；新用户和修改PATH都不等于干净系统 |
| W08 | 安全与显示 | 正常用户权限；原始安全提示与是否阻止；实际屏幕下文字、裁切、按钮；不关闭防护来取得通过 |
| W09 | 原生源码复测 | 固定代码下执行原检查、worker检查和新增进程回归；自己构建包单独记录，不与下载包混用 |

W01—W04优先完成，W05—W09按条件继续。缺一项不填PASS，允许部分提交。没有Windows实测通过也不妨碍第二轮开发；已有真实资料若显示跨系统数据丢失、共同程序错误等严重问题，单独交规划者按影响处理，不因为排期自由而忽略缺陷。

## F05｜选做：美术素材预检工具

目标：以后生成大量PNG人物、牌框、图标时，在导入游戏前发现机械性错误。输入是人工维护的小型清单与本地图片，输出机器可读JSON和简短Markdown报告。工具与游戏运行程序完全分离，可有可无，不作为构建前置步骤。

| 验收编号 | 内容 | 可观察结果 |
| --- | --- | --- |
| A01 | 文件完整性 | 缺图、重复ID、大小写路径重名、无法读取分别报错 |
| A02 | 基础PNG检查 | 签名、IHDR、尺寸、颜色类型与位深、块长度/CRC、结束块检查；不解码图像内容 |
| A03 | 期望尺寸 | 清单尺寸与实际不符时明确显示两组数字 |
| A04 | 透明声明 | 区分有alpha或tRNS声明与无声明；不能据此声称图中已有透明像素 |
| A05 | 相同文件提示 | 不同ID的同字节SHA-256重复列为warning；不判断近似画面或抄袭 |
| A06 | 只读安全 | 不修改素材、不联网、不追随链接或越出输入目录；资源超工具预算时停止该项并说明 |
| A07 | 结果稳定 | 相同内容、参数的实质报告相同；顺序稳定，路径为相对路径，无个人目录和时间戳噪声 |
| A08 | 独立可运行 | Python3.11标准库即可，中文/空格路径测试，README给一条命令；不改根依赖 |

不做智能画风评判、人物一致性判定、图像生成、自动抠图、自动改尺寸、正式美术分配或源图覆盖。不接入游戏、不修改卡牌和规则，不做另一个复杂编辑器。字体不在输入和交付范围，不上传任何字体文件。

规格和字段以 [程序设计](../architecture/R01-friend-design.md) 为准；Codex执行，不扩写本PRD。没有领取选做包时不默认开始。
