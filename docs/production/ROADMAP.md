## 第一轮通向正式实现的条件

- T01 的运行证据、Teddy 的玩法答案与 ChatGPT 正式规则稿分开保存，未知多人结果没有被程序猜定。
- T02 记录 Windows 和 macOS 的真实可用程度、离线运行、打包与 AI 风险；欠缺的目标平台测试继续挂在进度板。
- T03 的画面选择仅批准所说明的布局与画风，不能自动批准示意人物、功能或数值。
- ChatGPT 完成正式产品 PRD、正式架构、可追溯的验收案例，再发 R02 包；当前第一轮实验架构不代替这些文档。

先看首次执行返回的实际工作量，再安排日期。总进度按已通过的包及轮次结束条件计，不用“生成了多少代码”估算百分比。
