## 本包目标

实测 ChatGPT 已选择的 Electron + React/TypeScript + Python 子进程方案，拿到可复查的跨系统与离线证据。本线程不再做选型，也不把实验程序包装成成品。

## 先调查可用设备

记录执行环境 OS、CPU、是否有桌面、可访问 Windows/macOS 哪一端。没有 Windows 或 Mac 实机不假装已有；先完成能做的工作，给另一端一份准确测试步骤和对应包。Windows 优先关注朋友的笔记本，Mac 关注 Teddy 的实际机器。

## 工作

1. 在独立实验目录建立 ARC-R01 所述程序。版本用受支持稳定版，记录 exact 版本和可复现依赖清单。
2. 按协议跑 health、本机测试档案、固定双人案例和 choose_easy，校验错误、超时、退出回收。六席位只是固定显示样本，不实现多人出牌。
3. 制作带 Python 的轻量包。开发环境可安装依赖；给测试者的运行包不要求 Python/Node。关闭开发服务并断网重新启动，检查素材、档案与规则调用。
4. 分别记录 Windows/macOS 的构建、真实窗口、离线、中文空格路径、十次启停。缺一端明确 PARTIAL，给可执行清单；不通过关闭系统安全功能来运行包。
5. 独立检查既有权重 CPU 推理可用程度，强制报告真实对手来源；模型失败或回退不能写模型通过。不改 rl_ai.py／gui_deidei.py；需要修改就列问题，等 b 包。
6. 记录轻量包体积、冷启动、内存和 AI 请求耗时，说明机器和测量方式。不给没有测量过的“预计性能”填实测表。
