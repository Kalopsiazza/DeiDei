# DeiDei · 一拍逆转（6 秒视频生成包）

本次交付：真实游戏欢迎流程、首尾帧和生成提示词。视频由用户在自己的工具生成，当前游戏尚未播放这段视频。旧 v3 的两次全屏牌遮挡镜头已排除于新流程。

## 镜头与节奏

| 时间 | 动作 | 镜头／反馈 |
|---|---|---|
| 0–0.8 秒 | 首帧就是交锋前一瞬。银发角色冲向黑甲对手，对手射出红色刀牌。 | 低机位向前冲，不先站着展示人物。 |
| 0.8–2.6 秒 | 青色晶体牌架住刀牌，红青火花爆裂。她顺势旋身，以手中卡牌切出一记反击。 | 跟随侧移，攻击路径明确；只做一次交锋。 |
| 2.6–3.9 秒 | 反击击中对手胸前核心，对手崩成发光的牌片。 | 约 0.08 秒打击停顿、短促震动。不给全屏白闪。 |
| 3.9–5.4 秒 | 镜头跟住一张旋出的牌，战斗双方退出构图。卡牌翻至牌背，飞到右侧。 | 从动到静，落到原大厅的构图；牌始终不遮满全屏。 |
| 5.4–6 秒 | 尾帧构图固定：左侧大厅空出来，右侧一张轻斜的红黑金纹卡牌。 | 稳定持帧 0.6 秒；文字由游戏绘制。 |

声音建议：开头衣料／冲刺风声；格挡清脆玻璃金属声；反击低频撞击加短切；碎牌尾音逐渐消散。音乐在尾部留住底音，避免结尾突然静音。无需台词。

## 首尾帧

- `first-frame.png`：生成的战斗首帧（1672×941）。角色与大厅参考现有 `menu-character.png` 和 `menu-environment.webp`，不是已有实战规则的结算截图。
- `last-frame.png`：1920×1080，从正式 Electron 的 `WelcomeEntrance` 标题状态直接导出，隐藏文字和开发按钮。大厅、牌背与正式游戏使用同一资产。
- `../HALL-ASSETS.md`：现有大厅与牌背素材的来源记录。首帧使用内置 imagegen，未调用视频服务或 Kimi。

在生成工具里：首图指定首帧、尾图指定尾帧；6 秒、16:9、1080p，24 或 30 fps。工具若有独立角色参考槽，可加原 `menu-character.png`，不要用人物图替换首帧。人物、建筑和牌背纹样都以提供图片为准。

## 直接复制的提示词

```text
生成一段恰好 6 秒、16:9 横屏的高品质二次元游戏开场战斗。第一张图片是严格首帧，第二张图片是严格尾帧。请遵循两帧的美术、建筑、角色与卡牌设计，动作高速、凌厉，有清晰的因果和打击感。

场景始终在同一个 DeiDei 扑克牌大厅：左侧红月、宏伟台阶、暗色高柱，红色长帷幔与悬挂的金纹扑克牌，远处青蓝雾光连廊，黑色镜面石地板。主体是首图中的银发红瞳成年女角色，青蓝三角耳饰与发饰、红黑长外套、米白上衣、黑长裤，服装与面容保持一致。敌人只有一个，黑色无面具象的棱角甲胄，红色能量接缝。

0–0.8 秒：从首帧直接起动，女角色向对手疾冲，对手的红色刀牌迎面射来；低机位镜头快速推进，发丝和衣摆受惯性甩动。
0.8–2.6 秒：她用一张青色晶体卡牌精准架住刀牌，红青火花沿碰撞边缘迸射，紧接一个流畅旋身，用手中卡牌发出锐利弧形反击。镜头侧向跟随，使格挡、旋身和攻击轨迹看得清楚。
2.6–3.9 秒：反击明确命中对手胸前能量核心，一瞬约 0.08 秒的打击停顿后爆发；敌人随冲击崩解成发光卡牌碎片，沿攻击方向散开。不出现血液。镜头短促反震但不失去目标，不做全屏白闪。
3.9–5.4 秒：镜头跟随一张完整的红黑金纹牌旋转飞出；女角色退出左侧，碎片逐渐散尽。这张牌露出尾图相同的金色罗盘星纹牌背，平稳来到画面右侧，轻微倾斜。镜头迅速减速，水平线和大厅透视收敛到第二张图片。
5.4–6 秒：严格停在尾图构图。人物和敌人都已离开画面，只留下原大厅和右侧悬浮卡牌。最后 0.6 秒稳住相机、卡牌位置、比例、倾斜角度和光线，左侧留空以便游戏之后显示标题。

总体节奏先快后稳，只有一场连贯交锋，不剪成多个无关战斗，不做慢动作人物展示。不要让卡牌飞近镜头遮满全屏。不要生成标题、字母、字幕、UI、水印或任何文字。不要改变角色脸、发色、服装，不增加人物，不改变大厅建筑，不突然切场，不使用鱼眼、频繁乱晃、镜头翻转、黑场、故障闪烁或全屏白色爆炸。最后一帧必须尽量严格复现提供的尾帧。
```

## 接入与验收

正式流程已用同一大厅和牌背：标题／进入牌厅 → 标题退场 → 同一张牌在 1.4 秒内翻面并移到中央 → 命名和头像 → 新手实战或主菜单。新手实战调用原有真实 worker，不复制规则逻辑。

已有档案可从主菜单「开发预览 → P01 · 首次进入／欢迎建档」反复体验；预览不保存。没有档案时走真实创建接口，成功后显示去向选择。重建损坏档案仍需确认并备份原文件。

成片到手后再检查头尾一致性。提供的尾帧与 UI 同源，但无法保证视频模型遵循尾帧到像素级；若末帧漂移，可在接片时用 150–250 毫秒衔接到这张精确尾帧，再淡入游戏标题。当前尚未加入视频播放器或占位文件，避免用户先下载不存在的成片。16:9 的 1366×768 和 1920×1080 卡牌尺寸保持比例；其他宽高比需对成片裁切重新验收。
