# 新手实战教程 PRD 与策划流程

2026-10-01 · 用户授权：策划后直接按 VEW 实现。中风险本地功能；扩展本机 worker 的教学会话，原规则核心、随机单人及联网行为不变。继续复用 r04-t01-b 工作区；其他线程改动保留。

## 目标与范围

第一次玩的玩家，能在真实牌桌亲手选择、确认、共同揭晓，并读懂 DD 与攻守关系。规则图鉴右上角「新手实战」入口，可重复进入、随时暂停和退出，不自动抢占普通单人、不改档案格式。暂不教特殊资源、复制、炸药或多人。

使用同一牌桌、选牌按钮、提交动画、资源和出招历史；仅先展示攒、防、bi 三牌，其可用性和费用来自原核心。教学对手清楚标注身份，在玩家输入前固定合法动作。教学会话仍由 MatchSession / resolve_round 结算，不播放预制结果。

## 教学分镜

|阶段|真实局面与对手|玩家任务|界面指导与反馈|
|---|---|---|---|
|1 攒一拍|双方从 0 DD 开始；对手攒|点攒，再确认|指向攒；选中后指向确认；先解释 DD 是出招资源，结算后指出本人 DD 从 0 到 1|
|2 挡住攻击|沿用上一拍；对手 bi|点防，再确认|提示对手将练习 bi；指向防；结算说明防挡住 bi，本人原有 1 DD 仍在|
|3 出招取胜|本人 1 DD、对手 0 DD；对手攒|点 bi，再确认|指向 bi；结算说明消耗 1 DD、击中正在攒的对手，第一场结束|
|4 自己试一场|明确新开一场，双方资源归零|观察对手资源，从三张牌中自行选择，赢下练习|撤掉选牌指示；对手按自身 DD 预先固定：无 DD 攒、有 DD bi。可主动请求提示；每拍结算后手动继续|
|完成|独立练习胜利|进入普通单人或返回菜单|总结三牌作用；允许重练|

第一场非目标选牌可点、可看，但确认时给简短纠正，不提交也不扣资源；指示不会替玩家点。独立场允许所有可用三牌，真实输赢；输了明确原因并从独立练习起点重试，不重做已完成三课。双方平手时继续。练习中的防仍会按原规则增长聂湘充能，但不在基础三牌教程展开讲解。

## 交互与视觉

教学说明固定在牌桌上方，硬边玻璃、红黑/冰青沿用现有风格。短标题加一段与当前操作相关的指导。CSS 高亮当前目标卡或确认按钮，并显示「点这里」指示；高亮不盖住点击区域。玩家选中正确牌后引导才转向确认；错误牌显示纠正。键盘和鼠标同样有效。

不使用遮住牌桌的整屏说明弹窗。三牌操作区保持大字号，其他高级卡暂不出现；资源只重点展示 DD，完整资源仍可从局势查看。提交期间不再指示选牌；揭晓保持到玩家手动继续，原确认/结算不能跳过。暂停、冻结、错误提示仍有效。减少动态时关闭循环指示和入场动画，但保留边框、文字及真实状态。1000×650 以上不挡牌或按钮。

## 状态与接口

新 start_tutorial 使用已保存本机身份；只接受固定字段，无自定义脚本/状态输入。tutorial_next 绑定当前 view_id，仅揭晓阶段可推进；重复相同请求不二次推进，旧局面与错误阶段拒绝。每个新练习有新 match_id，资源由 new_match 初始化；退出关闭 worker，不保存练习状态。

DesktopView 增加可选 tutorial 元信息：stage、step、target_entry_id、won。普通对局不含此字段。renderer 只解释教学步骤，不判胜负；won 来自真实 resolution。教学结果由教程面板承接，不进入普通整场结果切换。揭晓计时为 untimed，等待手动继续。
