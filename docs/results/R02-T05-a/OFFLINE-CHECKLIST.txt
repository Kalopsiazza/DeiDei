DeiDei 第二轮 · 单人内部测试版（R02-T05-a）

请先完整解压，保留应用和随附资料。
macOS Apple Silicon：打开 DeiDei R02.app。
Windows x64：进入应用文件夹，打开 DeiDeiR02.exe。不能只复制 exe。
不需要安装 Python、Node 或 Git；不用联网注册账户。

首次启动：创建本机昵称和头像 → 单人对局 → 开始单人对局。
选一张可用牌并提交；对手为现有临时随机对手。结算后可再来一场。
手册可从菜单查看。档案与设置保存在当前系统用户的应用数据目录；对局不保存。
应用文件不完整时，请重新取得并完整解压测试包，不要从其他版本补文件。

签名与测试边界：Mac 为 ad-hoc 签名，未经 Apple 公证；Windows 未签名。
系统可能显示来源或发布者提示。遇到系统阻止，请保留提示交回维护者，不关闭防护或以管理员身份运行。
本包不承诺 Windows 10、Windows ARM、Intel Mac、Linux 或更旧系统可用。
CI 运行通过不等于你的电脑、物理断网或无开发工具的电脑已通过。

可离线保存的人工复测步骤：
1. 记录包名、SHA256、系统与 CPU、机器原有 Python/Node/Git 状况。
2. 在线先退出所有游戏进程。由本人断开网络，然后冷启动，读取手册。
3. 至少完成三场真实对局；退出游戏再开，核对昵称与设置。
4. 独立测试系统账户的新档案离线首启另行记录，不覆盖已有私人档案。
5. 记录安全提示、失败步骤与真实截图；未做的项目标为未测。

本轮使用占位美术，不含联机、自动更新或旧训练模型；不是正式发行版。
