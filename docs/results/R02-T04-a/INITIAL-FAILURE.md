# 开发阶段失败记录

首次未提交实现的真实窗口测试已走通对局，但在 worker 空闲退出后，下一次 getView 重新启动空 worker，返回 SESSION_CLOSED。页面显示「本场已结束」而不是要求的「本场中断」；该次检查未计为通过。`live-smoke-failure.png` 为当时实际窗口截图，不属于最终受测代码证据。

原因是原桥接自动重启只被请求期间的错误捕获覆盖，空闲退出没有被 WorkerPort 记住。已加入每进程 failure 状态，使后续读取先中断而不启动新 worker，并添加真实空闲退出测试。最终固定代码上的该回归测试与窗口复测均通过。

首次测试清理还被正在进行的场次退出确认阻塞，测试记录未能正常收尾；随后按已核实的测试进程 PID 回收自己创建的 Node/Electron/worker。窗口测试专用入口现先关闭自己持有的 WorkerPort，再退出 Electron。普通用户的对局退出确认仍保留。
