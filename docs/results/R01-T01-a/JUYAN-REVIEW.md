# 距喦专项报告｜第40轮反馈已收口

当前主规则v0.38。本次同学反馈已由用户转交，随后用户确认防御≤1/3；原先≤1、能挡bi的暂行定义已被覆盖，重复buff不叠加不再是旧代码候选。独立防御P3的通用扩展仍随主规则延期，不是本次距喦两项问题尚未回答。

## 当前规则

距喦0DD可用、原始攻击0、防御≤1/3；可以挡普通削和强化削，不能挡强度1的bi或更高强度攻击。防御逐来袭独立比较，不把多次攻击的数值相加，也不因为挡过一次而消耗防御。

每次使用授予一份后续强化削资格，**同时最多一份，不叠加**。已有buff时再次出距喦仍只有一次资格；下一次合法削会使用它，之后再次出距喦可重新获得一份（依据无额外次数上限与授予规则推导）。不增加多层buff或“待使用次数”库存。

buff在同局保留到下一次合法出削，中间攒或出其它普通招式不自动清除；曾义清空以及新局全重置会清除。强化削仍要求有buff且持有至少1/3DD，实际扣0。只有0DD时削不可出，异常请求拒收且不消耗buff。

防御与授予buff是独立效果，不以挡住攻击作为授予条件。本轮作用完整记账后才统一淘汰、结束或重开；不能把已淘汰者的账面buff当作下一局可用资格。

## 同学反馈与数值确认

用户提供的截图确认：第一项“确实只有一次强化削资格”；第二项指出距喦“不能挡bi”。截图是用户转交的规则反馈，不是程序执行证据。用户随后对“防御由≤1改为≤1/3”的询问答复：**采用防御≤1/3**。

因此，buff不叠加来自同学反馈；具体防御≤1/3来自用户后续明确确认，不能将这个数字伪称为截图直接提供。原话及说明见ANSWERS第40轮。
