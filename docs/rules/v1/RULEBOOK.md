## 阅读约定

`DD` 是积攒的主资源；攻击强度、防御数、可吸收的 DD 与实际费用分别表达。`≤x` 表示本次来袭强度不超过 x；`=x + 类别` 同时检查数值相等和对应攻击类别。`∞` 是正无穷，能挡住本版任何有数值的攻击，但不替代明确的直接淘汰条件。

本文的 E01—E33 是阅读编号，R01—R28 是规则编号，都不要求运行程序沿用旧枚举。每条规则都可用这些编号定位。后续改变规则时修改原条目和受影响案例，保留版本说明。

<a id="R01"></a>
## R01｜回合、一局、整场

**一回合**：所有仍参战的人各出一招，随后一起揭晓并完成全部判定。**一局**：这些人从初始状态开始，连续进行尚未出现淘汰的回合。**整场**：由一局或多局组成，淘汰者离开比赛，存活者可能重新开局，直到产生唯一赢家或所有人淘汰。

一局初始时，所有人的 DD、雷电、聂湘充能、炸药库存与放置进度、强化削资格、出招历史、可复制记录、使用次数和曾义进度都回到初始值。第一版联机一场有 2—6 位真人；观众不参加招式判定。离线暂定本人对一个 AI。

默认向本回合其他参战者出招，没有选目标操作。某些效果只对符合条件的对象发生，不能因此把它改成玩家指定目标的招式。

<a id="R02"></a>
## R02｜选择与合法性

资格只看本回合开始的资源、记录和次数；不能借同回合尚未获得的资源提前出招。灰色不可用牌不能提交。异常、无效、重复或过期请求不产生第二次行动，不扣资源、不用掉资格、不写历史，也不推动回合。

一人每回合只提交一个入口。曾义第二回合由系统生成休整动作，不接收另选招式。超时替代动作由房间安排提供，仍接受同样的资格检查；它与主动提交非法牌的处理分开。

<a id="R03"></a>
## R03｜四个判定阶段

| 阶段 | 本阶段完成什么 |
| --- | --- |
| P1 准备 | 检查资格，解析来源与完整实际招式，计算一份支出，选择复合招分支，得到全场本轮属性与成功条件 |
| P2 原始作用 | 逐次处理原始攻击、防御、资源效果及直接淘汰；反弹在这里登记回击，暂不执行 |
| P3 回击 | 执行已经登记的原值回击，只回到对应原攻击者，读取本阶段有效的防御 |
| P4 汇总 | 支出一次，合计作用、资源、次数、历史和延迟进度；列出淘汰与击杀；随后判断同局继续、存活者新局或整场结束 |

每阶段先处理全场，再进入下一阶段；不按座位先后让某个人跑完整个回合。试算也遵守这些规则，但不写入真实状态。

<a id="R04"></a>
## R04｜同回合效果保留与击杀

受到致命作用的人，本回合已经成立的出招仍完整发生：攻击、反弹、清空资源、吸收等都不会因较早的一条致命记录消失。淘汰是本回合的结果，不能拿它重新生成本回合的招式属性。

不同玩家分别有效击杀同一个人，每位作用者都记一次击杀；目标最终只淘汰一次。同一作用者多次命中同一目标，击杀人数仍只记一人。被挡住的攻击不能因目标另被他人淘汰而分到击杀。自 bi 失败造成的自身淘汰不记为击杀自己。

<a id="R05"></a>
## R05｜伤害、格挡与直接淘汰

经典玩法没有血量累减。每条有数值的正攻击若未被抵消或挡住，就登记目标被击杀。强度为 0 的动作不产生一条“0 点攻击”。攻击不相加穿透防御，防御也不因挡过一次而耗尽；每次来袭独立判断。

本版另外有三类无伤害数值的直接淘汰：自 bi 未成功而自身淘汰；田利军遇反弹、吸收或云；小贝遇具有攒效果的动作。它们按各自条件记录，不能伪装成 10000 或无穷伤害，也不能因此生成反弹或吸收收益。

<a id="R06"></a>
## R06｜攻击之间的对撞

普通攻击以及聂湘、两贝的 P2 对撞防御等于该次实际攻击强度，通常按 `来袭 ≤ 自己强度` 防住。相等时该对双方相互抵消；不相等时较强者能击杀较弱者，但后者仍可攻击其他人。明确例外优先处理。

复合招采用普通攻击分支时，取分支的攻击和对撞数值。旋转三雷的三雷分支是 3，翻转沃尔沃的沃尔沃分支是 4，不能把费用 6、8 当成强度。

对撞防御只在 P2 生效，P3 不再挡自己的攻击被反弹回来的数值。成功自 bi、成功历强、曾义的持续保护则按各自规定覆盖 P2/P3。

<a id="R07"></a>
## R07｜普通削与强化削

普通削强度 1/3，花 1/3 DD；在 P2 遇到当时有效、防御数大于 0 的防御即可被挡，四种专属防御也能挡它。这项普通削例外不适用于强化削。

持有距喦给予的资格时，下一次合法出削自动成为强化削：仍需持有至少 1/3 DD，但实际扣 0 DD，强度仍为 1/3，并用掉这份资格。普通防御和任何档位的放炸药都挡不住它；四种专属防御也不匹配它。距喦、田利军、反弹、吸收、云可挡，攻击对撞与持续保护按本版数值规则处理。吸收挡强化削只防御，不获该攻击的 DD。

<a id="R08"></a>
## R08｜防御比较与特别匹配

先处理明确的攻击目标例外和禁防／允许匹配，再做一般数值比较。专属防御既要求数值相等，也要求对应攻击类别；来源不影响通常匹配。普通削按 R07 单独处理。

| 防御动作 | P2 防御 | 关键说明 |
| --- | --- | --- |
| 普通防御 | ≤1，另可挡大 bi | 不挡强化削；不会因为可挡大 bi 就挡住 Pragon、三雷或沃尔沃 |
| Pragon 防 | =2 且 Pragon 类 | 能挡普通削；不能挡 bi 或强化削 |
| 三雷防 | =3 且三雷类 | 可匹配旋转三雷选出的三雷分支及雷电三雷；其另一分支按自 bi 目标条件处理 |
| 沃尔沃防 | =4 且沃尔沃类 | 普通、炸药、翻转的沃尔沃分支都可匹配 |
| 聂湘防 | =7/2 且聂湘类 | 能挡普通削；不能按“≤7/2”扩大范围 |
| 距喦 | ≤1/3 | 明确可挡强化削，不能挡 bi |
| 田利军 | ≤9 | 可挡强化削、大 bi；明确挡不住两贝 |
| 放炸药 | 第 1/2/3/4+ 次为 ≤1/3、≤1、≤2、≤3 | 任何档位都不能挡强化削 |
| 反弹 | ≤100 且符合反弹匹配 | 大 bi、两贝被明确排除；聂湘可反弹 |
| 吸收、云 | ≤100 且符合吸收匹配 | 聂湘与两贝被明确排除；大 bi、沃尔沃可防 |
| 成功自 bi／曾义两回合 | ≤∞ | P2/P3 持续有效 |
| 成功历强 | ≤9999 | P2/P3 持续有效；仅符合重复条件者才受到它的 10000 攻击 |

独立防御在 P3 的潜在扩展不由本文补猜。本版能收到回击的实际出招者只有可被反弹的攻击动作，已经有明确的 P3 结果；证明与新增招式时的处理见 R28。

<a id="R09"></a>
## R09｜资格、来源与一次支出

一份动作只支付对应入口的一份费用。普通来源支付普通费用；炸药、雷电、张新伟和曾义奖励入口，使用自己的资格和支出，不再叠加原招普通费用。次数按合法施放计，效果落空或本人被淘汰也不退费。

张新伟、历强、曾义各为每局一次；免费大 bi 受本局一份奖励限制。其他招式没有额外的每局总使用次数上限，但仍检查资源。炸药防御到顶不表示只能放四次。

<a id="R10"></a>
## R10｜反制上限与类别

反弹、吸收、云的数值防御上限为 100，等于 100 时通过上限检查，仍需检查类别；大于 100 时该次防御及对应反制均无效。一次超限不取消它们对其他来袭的效果。

反弹排除大 bi、扇贝、小贝。吸收与云排除聂湘、扇贝、小贝。自 bi／历强的 10000 超过上限，不会生成回击或吸收收益。反制对田利军的直接淘汰按 R22 单独发生。

<a id="R11"></a>
## R11｜反弹

每次符合条件的来袭，在 P2 被挡住并登记一条原值回击；P3 只返回原攻击者，强度等于那次原攻击强度，不取全场最大值，也不向其他人发射。

回击只借用数值，不复制原招的费用、来源、资源效果或额外特性。它的击杀归反弹者，依据记录指向原来袭。同轮反弹者被击杀，也执行已经登记的其他回击。本版不产生回击的再反弹。

<a id="R12"></a>
## R12｜吸收与攒

吸收的防御与资源所得分别处理。它能挡住普通削、强化削、bi、Pragon、三雷、沃尔沃、大 bi，以及这些攻击已定义的不同来源和复合招普通分支；仍受 R10 限制。

| 被吸收的攻击 | 单次获得 DD |
| --- | --- |
| 普通削／bi／Pragon／三雷／沃尔沃／大 bi | 1/3／1／2／3／4／5 |
| 雷电来源三雷 | 3 |
| 张新伟复制上述可吸收攻击 | 按本次实际攻击对应 DD；不沿用过去的炸药零收益 |
| 曾义赠送的大 bi | 5 |
| 炸药来源的可防攻击、强化削 | 0，仍可以防住 |
| 聂湘、两贝、10000 条件攻击 | 无防御、无该次收益 |

每条合规来袭分别获益再相加；多个吸收者各自获得完整一份，不分摊；施放者只付一次 1 DD。反弹回击不成为另外一次吸收所得。

每名本轮具有攒效果的对手，使吸收者独立获得 1 DD，并取消该对手这一次 +1 DD。多个吸收／云只会取消同一份增长，不按人数扣攒者已有余额。田利军清空攒者也不撤销吸收者已经成立的收益。原本被第三者击杀的攒者和吸收者，仍完成本回合账目。

<a id="R13"></a>
## R13｜云与雷电

云沿用吸收的防御匹配，但不取得对手的 DD；对每位出攒效果者取消本次 +1 DD，不扣旧余额。每次合法使用云固定增加 1 雷电，与来袭次数、人数、是否挡住攻击无关。

雷电支出只能使用回合开始已有数量：3 雷电释放三雷，6 雷电释放完整旋转三雷。云首次免费以当前一局计，曾义不恢复首次资格，新开一局会恢复。

<a id="R14"></a>
## R14｜自 bi

本轮其他参战者至少一人实际出反弹、吸收或云，自 bi 即成功。成功时获得持续到本轮结束的 `≤∞` 防御，并只向这些合规对象施加 10000 攻击。不能因为自己成功，就对其他所有人造成 10000。

没有任何合规对象时，自 bi 未成功、无数值攻击、无防御，并直接登记自身淘汰。单纯两人都出自 bi 时都没有成功对象，因此全员淘汰，无人获胜。

复合招选到自 bi 分支时，完整继承这些效果；不能同时保留普通攻击。实际招式身份仍为对应复合招。

<a id="R15"></a>
## R15｜历强

只比较其他人本回合与上一回合的完整实际招式。至少一位合规重复者便成功；仅向这些重复者施加 10000，自身防御为 `≤9999`。曾义自动休整不算合规重复者。

是否成功先由重复事实决定；目标用无穷防御挡住 10000，也不会令历强变回失败。多个历强各自保留对第三人的作用，不能直接宣布互相抵消整轮效果。未满足重复条件的人不受历强攻击。

未成功时，回合开始 DD=0 才按攒处理，包含 +1 DD、吸收／云阻攒、田利军清空和对小贝的作用；完整实际身份仍为历强。DD>0 时攻击和防御都是 0，不攒，也不因同回合其他效果改变这次判断。合法使用成功或失败，都用掉本局唯一资格。

<a id="R16"></a>
## R16｜实际招式、来源与历史

例如“张新伟复制旋转三雷，选三雷分支”：入口是张新伟，来源是张新伟，完整实际招式是旋转三雷，本轮攻击类别是三雷。前两项决定取得方式，完整身份用于历史，所选效果用于当轮攻防。

历强因此认为普通三雷→雷电三雷是重复；旋转三雷→张新伟复制旋转三雷也是重复；连续旋转三雷即使换分支仍是重复。旋转三雷的三雷分支→普通三雷不重复。失败历强按攒后→普通攒也不重复。旧局历史不能作为新局的上一招。

<a id="R17"></a>
## R17｜张新伟与高阶记录

读取自己的最近一份仍有效的可复制高阶记录，不要求上一回合发生；无记录或本局已用则不可出。有记录时 0 DD 可用，不支付复制招的 DD、雷电、炸药、奖励库存或聂湘充能费用。复制聂湘在 0 充能时也合法。

高阶按本轮实际攻击强度 `≥2` 判断，另外明确禁止复制完整自 bi、历强、反弹。低强度动作和禁复制动作不覆盖旧的有效高阶记录。符合条件时记录完整原招；复合招按该次分支强度判断高阶资格，记录仍为完整复合招。

本次复制产生新的张新伟来源，不继承过去的来源、分支或成功状态。复合招重新选择分支，再生成本轮属性。曾义清空有效高阶记录后，不得从旧日志恢复资格；奖励到账不等于实际使用大 bi，实际出招后才能记录。新局也清空记录。

<a id="R18"></a>
## R18｜旋转三雷与翻转沃尔沃怎样选择

每个复合招整回合只取一个分支，全场共用；程序选择，玩家不按目标再选。旋转三雷候选为三雷／自 bi，翻转沃尔沃候选为沃尔沃／自 bi。

先解析全场的完整实际身份，确定哪些人属于复合招选择者，包括张新伟和其他来源产生的复合招。对于其中一人，只在“本人＋所有固定招式玩家”中试算候选；其他选择者的全部影响都排除。纯自 bi、历强的成功判断不属于自由分支选择，它们是固定招式玩家。

每个候选都计算到回击完成，比较本人是否存活，然后比较本人有效击杀的不同人数。两候选都会死亡时仍优先更多击杀；同等最优时随机取一个。对手吸到多少 DD 不参与评分，但吸收挡住攻击当然会影响击杀结果。

所有人分别选好后恢复全场，重新生成正式属性，执行一次真实结算。即使全场结果变坏也不重选；排除在试算外的人照常参战。这种危险度已经确认，不能改回全场最优或联合博弈求解。

<a id="R19"></a>
## R19｜炸药时序

本局第 n 次放置的防御上限为：n=1 时 1/3，n=2 时 1，n=3 时 2，n≥4 时 3；只在这次放炸药时使用。层库存与防御进度分开；兑换层数不会倒退放置进度。

T 回合放置，T 回合末仍未成熟；T+1 回合末成熟，T+2 回合开始才可兑换。不能在 T+1 选择阶段预支。每次有效放置只增加一个待成熟层。曾义清空库存、待成熟队列和防御进度；新局全清。任何档位都挡不住强化削。

<a id="R20"></a>
## R20｜普通防御、聂湘充能与聂湘

每次合法普通防御先得到 1 点充能，再为每次独立成功挡住的 bi、普通削或大 bi 各加 1。基础收益只记一次，额外不按回合封顶一次。挡两次 bi 共得到 3 点；挡一次大 bi 共得到 2 点。

普通聂湘持有至少 4 点可出，花 4 点、0 DD，剩余充能保留。攻击与 P2 对撞防御为 7/2。它能被反弹并在 P3 被原值 7/2 回击；吸收和云连防御也不生效。张新伟来源的费用按 R17，不扣这 4 点。

<a id="R21"></a>
## R21｜距喦

0 DD 使用，攻击 0，防御 `≤1/3`，挡两种削，不能挡 bi。每次合法使用授予一份强化削资格；已有一份时再使用仍只有一份，不能累计免费次数。

资格在同局一直保留到下一次合法出削；中间攒或用其他招不会自然过期。用掉以后再次使用距喦可以再获得一份。曾义清空和新局重开也会去掉资格。

<a id="R22"></a>
## R22｜田利军

首次 0 DD，以后每次 1/2 DD，原始攻击 0，防御 `≤9`。可挡大 bi 与强化削，明确不能挡两贝。

对每个具有攒效果的对手，清空其本轮最终 DD，包括旧余额与当轮增长。自身不会得到这些 DD。对手的攒被云／吸收取消，不会阻止这一清空；其他吸收者的独立收益仍保留。

遇任何实际反弹、吸收或云的对手，田利军被该对手直接淘汰，不使用伤害数值。不因田利军或反制者另被击杀而撤销作用；仍清空其他攒者，最后一起汇总。

<a id="R23"></a>
## R23｜小贝与扇贝

小贝强度 7，扇贝强度 10，通常使用同值 P2 对撞防御。任意两个两贝动作之间只抵消彼此原始攻击，不取消对其他人的作用。反弹、吸收、云均不能防住两贝，也无对应回击或吸收收益；田利军同样不能挡。更高数值持续防御照常比较。

小贝遇到攒效果时，由攒者直接淘汰小贝，小贝对该攒者的攻击不生效，但对其他人的攻击保留。攒者是否获得 DD、是否另被杀死，都不改变这个匹配。扇贝没有这项怕攒的弱点。

<a id="R24"></a>
## R24｜大 bi 的特别之处

大 bi 的实际强度是 5。反弹不能挡，也不能回击；这仍是一条强度 5 的攻击。普通防御有专门许可可以挡住它，并按 R20 获得充能；吸收和云可挡，吸收取得 5 DD；田利军按 `≤9` 可挡。不能把普通防御的许可扩展给所有能挡 bi 的招式。

炸药来源没有大 bi 入口；曾义赠送和张新伟来源可产生同一个大 bi。免费来源只改变支出，不能改变强度、克制、历强重复或通常吸收收益。

<a id="R25"></a>
## R25｜曾义与延迟奖励

每局主动使用一次，0 DD 可发动，没有额外固定费用。发动 T 回合与下一回合 T+1 自动休整，均攻击 0、防御 `≤∞`，覆盖 P2/P3；休整不再消耗一次使用资格，也不允许另选牌。休整明确不触发历强。

两回合都清空本人的：DD、雷电、聂湘充能、成熟与未成熟炸药、炸药防御进度、强化削资格、有效最近高阶复制记录。保留云、田利军、张新伟、历强、曾义等使用记录，不能恢复首次免费或每局一次资格。完整历史可保留作说明，但不能用它恢复已清的复制资格。

| 回合 | 效果 |
| --- | --- |
| T | 主动发动，保护与清空，本局资格已用 |
| T+1 | 自动休整，再保护与清空；休整不计历强重复 |
| T+2、T+3、T+4 | 正常行动，曾义保护已经结束 |
| T+4 末 | 得到一份免费大 bi，发放一次 |
| T+5 开始及以后 | 可以用掉或留着；不兑换成 5 DD，不自动出招 |

奖励使用时实际是大 bi，来源为曾义赠送，0 DD、扣一份资格。它不继承休整的历强豁免。免费大 bi 不在曾义技能自身的清空名单；本版每局只能发动一次，不需要多次奖励累计或再次清掉旧奖励的玩法。若中间发生新局，旧局休整、等待或已经得到的奖励全部取消，按 R26 重新开始。

<a id="R26"></a>
## R26｜本轮账目完成后再推进整场

| 完整结算后的情况 | 接下来 |
| --- | --- |
| 无人淘汰 | 保留本轮得到的全部状态，在同一局进入下一回合 |
| 有人淘汰，至少两人存活 | 仅存活者开新局；玩法状态全部恢复初始 |
| 只有一人存活 | 该人获胜，本场结束 |
| 无人存活 | 全员淘汰，无人获胜；赢家为空，本场结束 |

新局清空所有资源、buff、当前规则历史与复制资格、炸药库存／待成熟／进度、各种次数、曾义休整／等待／奖励；每局一次恢复未用，云与田利军恢复首次免费。已淘汰者不因此重新加入。

先留下本回合完整收益、击杀与死因记录，再生成新局初始状态。例如某人这轮吸收净赚 4 DD，但有人淘汰而他与另一人重开，新局 DD 仍为 0。账户、房间成员身份、观战身份及整场淘汰结果不属于这份玩法清空；房间超时管理也不能因玩法新局被擅自重置。

<a id="R27"></a>
## R27｜玩家可见信息与选牌交接

采用合法牌在前、灰牌在后的两个从左到右分组，牌面适当缩小以容纳更多招式，支持并显示数字键 1—0。资源跟着本人的卡牌，倒计时在卡牌上方。组内顺序、超过十张牌的键位安排与具体尺寸留给页面规格，不能从概念图反推。

卡面需要区分“需要持有”和“实际花费”，尤其强化削、张新伟、聂湘及兑换入口。说明能展开查看详细规则。揭晓前不把其他人本回合的选择发送给玩家或观众；显示已准备状态不等于公开所选牌。演出先后不影响已经计算的结果。

<a id="R28"></a>
## R28｜本版未扩展的事项

独立防御在 P3 的一般范围没有新增假定：反弹只回击造成合规原始攻击的人，本版这种人使用的是普通攻击、聂湘或复合招的普通分支，对撞防御在 P3 无效。两贝和大 bi 不被反弹，条件 10000 超限；独立防御、攒与曾义无可反弹原始攻击。因此当前合法对局不会要求一个纯防御动作接收回击。

未来若加入“原始攻击＋独立持续盾”或新的反弹方式，就要先增加明确规则和案例。不能把当前无法出现的组合写成已确认的防御失效，也不做自动回击递归。

血量、贷款、火力大乱斗、分队、多人 AI、等级与解锁都不在本规则版本中。旧学习模型观察截断值不能变成资源上限。房间掉线秒数、观众上限、第三次缺席的移除时点等由房间 PRD 另行规定，不从攻击条目猜定。
