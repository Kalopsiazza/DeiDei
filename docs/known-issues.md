# 已知问题

## #1：模拟会共用炸药列表

`simulate_turn` 对玩家状态的复制没有单独复制 `bombPending`；推进炸药列表可能改变输入状态，影响 AI 对同一局面的多次试算。见 [Issue #1](https://github.com/Kalopsiazza/DeiDei/issues/1)。

`tests/test_known_regressions.py` 用一个明确的 `expectedFailure` 记录它。CI 允许这一项已知失败，并在输出中显示数量；这不代表问题已修复。修复 PR 应去掉标记、保留测试，并加上相同局面反复模拟与双方状态隔离的测试。不要将其他问题也改成预期失败。

## 部分玩家说明与代码不同

例如 GUI 的部分专属防御说明写着能挡 Bi，而 `blocks_attack` 中四种专属防御都挡不住 Bi；其他位置的提示也存在不同说法。现有测试记录代码行为，后续由熟悉原玩法的同学确认后单独修复文案或判定。不要因为看见一段文字就批量改规则。

## 训练复现和模型效果资料不足

现有训练环境和权重不足以复现完整训练过程，旧说明中的训练数量和水平评价暂未验证。参见 [模型说明](model-card.md)。

## 启动与界面验证仍有限

原有新手说明中“环境已经装好”仅适用于原作者电脑，fresh clone 不包含 `.venv`。新贡献者请按 README 安装。基础 CI 不运行完整桌面窗口、不安装全部机器学习依赖、不验证跨平台显示；这些需要对应贡献者说明实际测试系统和结果。
