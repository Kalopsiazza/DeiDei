| 编号 | 输入与动作 | 预期 |
| --- | --- | --- |
| D01 | 原Q01，尚未断线时检查限流拒绝 | UUID对应；last_command_seq/cache、room.seq、match及policy不变 |

## S01—S18｜安全连接准备

| 编号 | 检查 | 预期 |
| --- | --- | --- |
| S01 | 无新参数启动原回环服务与原客户端 | 既有房间样本与离线功能保持 |
| S02 | 回环TLS有效证书+正确CA | 真实wss、rooms-1.1握手和完整对局成功 |
| S03 | 只给证书或只给key、不可读或错配 | 明确启动失败，没绑定端口，没有降为明文 |
| S04 | 非回环bind但缺flag或TLS | 参数校验拒绝；纯测试不真实监听外部地址 |
| S05 | 非回环bind+flag+TLS参数组合 | 无网络的配置检查允许；不宣称公网已运行 |
| S06 | 明文远端ws、其他scheme、凭据/query/fragment/错误路径 | endpoint拒绝，无网络请求 |
| S07 | 正确wss域名、IP、默认443与指定端口 | 格式接受；实际连接仅用回环测试目标 |
| S08 | 未知CA、错误SAN、过期证书 | 真实握手失败，没有session.open，没有ws回退 |
| S09 | 对TLS端口发明文、HTTP非目标路径或浏览器Origin | 安全拒绝；其他房间和离线模式可用 |
| S10 | 成包有合法只读配置与不同环境地址 | 配置优先，环境不能覆盖；地址不经renderer输入 |
| S11 | 成包配置null、坏JSON、重复键、过大、未知字段或读失败 | 关闭或明确配置错误；不偷偷读取另一个地址，离线可用 |
| S12 | 成包配置缺失、回环诊断环境；源码开发环境 | 前者仅接受回环，后者按开发校验，保持既有诊断能力 |
| S13 | main层到TLS服务，两玩家一观众连续两场 | 真规则结果一致；观众没有私密选牌和提交权限 |
| S14 | TLS对局中10秒改5秒 | 当前拍deadline不变，下拍5秒，旧请求重放不重复改设置 |
| S15 | TLS连接断开、同身份恢复、服务器重启 | 原房恢复遵守既有行为；重启拒绝旧身份，无重扣/重奖 |
| S16 | TLS房主提交后主动离开 | 当拍/揭晓后结束，无伪造赢家；成员离房提示清楚 |
| S17 | TLS服务持续停止后进入离线单人 | 包内或源码真实worker照常可用；不依赖CA/服务就能开始 |
| S18 | 测试结束与产物检查 | 所属端口/进程退出，临时私钥与CA不进入Git/运行包，日志无凭据 |

按L1/L2/L3/L4分别记录，不用纯URL单测替代握手，也不把Node成功替代真实Electron。缺环境保留NOT_RUN及原因。
