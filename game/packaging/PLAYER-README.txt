DeiDei R04 · 阶段内部测试包（R04-T02-a）

请先完整解压，保留应用和随附资料。应用文件名保留兼容命名：
macOS Apple Silicon：打开 DeiDei R02.app。
Windows x64 包（另行构建与验收）：进入应用文件夹，打开 DeiDeiR02.exe。不能只复制 exe。
不需要安装 Python、Node 或 Git；本地单人、新手实战和经典规则图鉴无需联网注册账户。

首次启动：观看或跳过开场 → 创建本机昵称和头像 → 开始新手实战，或进入主菜单。
本地单人：单人对局 → 准备页 → 开始对局 → 选可用牌并确认出招；终场可查看局势回顾或再来一场。
对手为临时随机合法策略，不是训练模型；当前没有运行时 AI 难度或单人选择时限。
新手实战复用真实规则结算；教程揭晓由本人继续。经典规则图鉴可查看、搜索招式和播放规则示例。
档案与设置保存在当前系统用户的应用数据目录；对局不保存。

好友房需要维护者提供已配置、可信的房间服务；本包不附带公共服务。
未配置时，好友联机入口显示服务不可用，本地单人、新手实战与图鉴仍可使用。
已配置服务支持 2—6 名玩家与观众；当前跨设备真人体验仍待验，不能以本机或脚本联调代替。
应用文件不完整时，请重新取得并完整解压测试包，不要从其他版本补文件。

签名与测试边界：Mac 为 ad-hoc 签名，未经 Apple 公证；Windows 未签名。
系统可能显示来源或发布者提示。遇到系统阻止，请保留提示交回维护者，不关闭防护或以管理员身份运行。
本包不承诺 Windows 10、Windows ARM、Intel Mac、Linux 或更旧系统可用。
源码检查、冻结 worker、签名完整性与成包 GUI 是不同验收层；构建成功不等于真人电脑、物理断网或无开发工具的电脑已通过。

可离线保存的人工复测步骤：
1. 记录包名、SHA256、系统与 CPU、机器原有 Python/Node/Git 状况。
2. 在线先退出所有游戏进程。由本人断开网络，然后冷启动，读取图鉴。
3. 至少完成三场真实单人对局；退出游戏再开，核对昵称与设置。
4. 独立测试系统账户的新档案离线首启另行记录，不覆盖已有私人档案。
5. 记录安全提示、失败步骤与真实截图；未做的项目标为未测。
